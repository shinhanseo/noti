# Room Active Learning 라벨 결과

## 라벨 분포

실제 Room 알림에서 Active Learning으로 선정한 40개를 검수했다.

### 공통 Actionability

- `GENERAL`: 35개
- `ATTENTION_WORTHY`: 4개
- `ACTION_REQUIRED`: 1개

### 사용자 개인 선호

- `GENERAL`: 36개
- `IMPORTANT`: 4개

공통 기준으로 일반이지만 개인 선호에서는 중요인 알림이 1개 있었다. 따라서 공통 Actionability와 개인 선호를 하나의 정답으로 합치지 않고 분리하는 현재 설계를 유지한다.

## 진단 결과

이 표본은 모델과 규칙이 충돌하거나 모델이 불확실한 알림을 의도적으로 많이 선택했다. 따라서 아래 값은 전체 실사용 정확도가 아니라, 어려운 표본에서 과도한 중요 판정을 확인하기 위한 진단값이다.

| 판정기 | 공통 3단계 일치율 | 개인 선호 이진 일치율 |
| --- | ---: | ---: |
| KoELECTRA | 47.5% | 45.0% |
| EmbeddingGemma + MLP | 60.0% | 65.0% |
| Granite Embedding + MLP | 72.5% | 70.0% |
| Kotlin 규칙 | 80.0% | 82.5% |

## 해석

- 기존 합성 데이터에 비해 실제 알림은 `GENERAL` 비율이 매우 높았다.
- 세 모델 모두 실제 알림에서 중요 알림을 지나치게 많이 예측했다.
- 현재 40개만으로 모델을 다시 학습하면 일반 알림에 과적합될 수 있다.
- 이 데이터는 우선 실제 알림 교정·오류 분석 세트로 사용한다.
- 이후 실제 알림 라벨을 누적하면서 학습용과 평가용을 분리한다.
