# v0.2 모델 선정 결과

## 담당 범위

이 문서는 Android 통합 이전의 AI/ML 결과만 다룬다.

- 데이터 필터링과 교차 검증
- 후보 모델 학습과 비교
- 전체 데이터 최종 학습
- Python 모델 저장과 재로딩 검증
- 구현 중립적인 가중치 JSON 내보내기
- 독립 추론 코드와 기준 확률 비교

Android 로딩 코드, 기기 성능과 배터리 측정은 포함하지 않는다.

## 후보 비교

합성 REVIEW 데이터 240개를 사용했다. 동일한 20개 `random_state`에서 각각 5-Fold `StratifiedGroupKFold`를 실행했으며 모든 평가에서 Template Group 중복은 0개였다.

| 순위 | 후보 | 평균 정확도 | 최저 정확도 | 평균 Precision | 평균 Recall | Brier | Log Loss | Python Joblib |
|---:|---|---:|---:|---:|---:|---:|---:|---:|
| 1 | Char TF-IDF + MLP(32) | 94.5% | 86.7% | 0.940 | 0.952 | 0.053 | 0.208 | 약 3.5MB |
| 2 | Char TF-IDF + ComplementNB | 93.4% | 85.4% | 0.933 | 0.937 | 0.060 | 0.221 | 약 54KB |
| 3 | Char TF-IDF + SGD Log Loss | 91.8% | 82.9% | 0.925 | 0.911 | 0.072 | 0.262 | 약 35KB |
| 4 | Char TF-IDF + Logistic Regression | 91.7% | 83.3% | 0.920 | 0.916 | 0.142 | 0.464 | 약 35KB |
| 5 | Char+Word TF-IDF + Logistic Regression | 90.6% | 82.5% | 0.921 | 0.892 | 0.126 | 0.423 | 약 42KB |

## 현재 선정 모델

합성 v0.2 데이터에서의 임시 1위는 다음 모델이다.

```text
문자 2~5-gram
→ TF-IDF 3,657차원
→ Dense 32 + ReLU
→ Dense 1 + Sigmoid
```

모델 이름:

```text
noti_char_tfidf_mlp_v0.2
```

선정 이유:

- 평균 정확도가 가장 높았다.
- 중요한 알림 Recall이 가장 높았다.
- Brier Score와 Log Loss도 다섯 후보 중 가장 낮았다.
- 최저 반복 정확도도 86.7%로 가장 높았다.

| 산출물 | Logistic Regression | MLP |

Joblib 크기는 Python 직렬화 형식의 크기다. Android에서 사용하는 실제 모델 또는 앱 용량과 동일하지 않다.

## 검증 결과

### Logistic Regression

- Joblib 저장 전후 최대 확률 차이: `0`
- Portable JSON과 scikit-learn 최대 확률 차이: `2.220e-16`

### MLP

- Joblib 저장 전후 최대 확률 차이: `0`
- Float32 Portable JSON과 scikit-learn 최대 확률 차이: `5.160e-09`
- Portable 허용 오차: `1e-6`

두 모델 모두 저장과 독립 JSON 추론 검증을 통과했다.

## 현재 결론의 한계

이 MLP를 실제 서비스의 최종 모델로 확정한 것은 아니다.

- 모든 수치는 합성 데이터에서 측정했다.
- 실제 사용자 알림 외부 평가가 없다.
- Pretrained Embedding + 얕은 MLP는 아직 같은 평가에 포함하지 않았다.
- 모델 확률을 실제 `±15점` 정책에 맞춰 별도로 보정하지 않았다.
- Android에서의 크기, 추론 시간, 메모리와 배터리는 측정하지 않았다.

따라서 현재 상태는 다음과 같이 표현한다.

> `noti_char_tfidf_mlp_v0.2`는 합성 v0.2 데이터에서 선정된 임시 최우수 AI 모델이다. 실제 익명화 외부 평가가 추가되면 후보 전체를 다시 비교한다.
